# 💻 Code Second Brain

The hub for everything code. Claude reads and writes here when you're working on projects.

## Sections
- **Projects/** — one note per project (goals, decisions, status). Mirror of your GitHub repos + Notion code projects.
- **Auto Notes/** — automatic session notes. When Claude finishes a coding session with you, it drops a dated summary here. See [[About Auto Notes]].
- **GitHub Activity/** — auto-generated daily. A sync script pulls your repo list and recent commits from GitHub. Don't edit these by hand; they get overwritten. See [[_GitHub Index]].
- **Notion Backup/** — local mirrors of important Notion notes. Notion is still the source of truth; this is your offline copy. See [[About Notion Backup]].
- **Reference/** — evergreen knowledge: snippets, prompts, how-tos, gotchas.
