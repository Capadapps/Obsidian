# About Auto Notes

This folder is Claude's automatic notetaking inbox.

**How it works:** Claude's global instructions (in `C:\Users\logan\.claude\CLAUDE.md`) tell it that at the end of any meaningful coding session, it should write a dated note here named `YYYY-MM-DD <project> - <topic>.md` covering:

- What was worked on and why
- Key decisions made
- Problems hit and how they were solved
- Open TODOs / where to pick up next time

You don't have to do anything — but you can also ask Claude at any time: *"drop an auto note for this session."*

Periodically skim these; promote anything evergreen into `Reference/` or the relevant `Projects/` note.
